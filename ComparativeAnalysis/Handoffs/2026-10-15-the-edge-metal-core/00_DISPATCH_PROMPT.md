# THE EDGE, the Metal core · dispatch

You are writing one new field, `edge`, for ten cells of a BaZi reading app in English, from a system you have never seen. Everything you need is in this folder; use nothing else. Read in this order: `prompts/04_READING_SYSTEM_PRIMER.md`, `prompts/00_MASTER_PROMPT.md`, `prompts/02_RULES_REGISTER.md`, `prompts/06_CAPS_BY_PAGE.md`, `prompts/07_REFERENCE_BENCHMARKS.md` (the 16 Personalities entries show the register of a strengths list), then `ELEMENT_GOD.edge.md` (the card: the construct, the chain, the checks, the exemplar), then the ten skeletons in `cells/`.

Fill `fields.edge.value` with `{"talents": [3], "places": [3], "action": "..."}` exactly in the card's shape. Set `_generated_by` to "fable-edge-v1". Keep every other key byte-identical. Write each filled file under the same name to the output folder you are given.
