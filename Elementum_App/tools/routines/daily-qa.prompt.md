# Pipeline

1. PREFLIGHT: `git -C D:\Elementum\Elementum_Project fetch origin` ; confirm main worktree is on main and in sync. Drift or a dirty tree is a finding to report, not a blocker.
2. SWEEP (from Elementum_App/): self-heal the browser first — `cmd /c "npx playwright install chromium >nul 2>&1"` (scheduled contexts cannot see sandbox-overlay installs). Ensure a dev server: try http://localhost:5173, else start `npx vite --port 5199` in background and set QA_BASE. Then run ALL of:
   - `node tools/qa-engine-regression.mjs` (exit 2 = Tier A regression = ON-FIRE)
   - `node tools/qa-route-sweep.mjs` (report: tools/qa-output/route-sweep/latest/report.json)
   - `node tools/qa-journey-sweep.mjs` (report: tools/qa-output/journey/latest/report.json)
   - Live health: elementum.life must be 200 + `<div id="root">`; push worker 200; stripe webhook returns 4xx for an unsigned POST (2xx or 5xx = finding).
3. TRIAGE — verify before reporting: open flagged screenshots with Read; a clip that looks fine is a false positive. Journey GESTURE step failures (wheel latch, dissolve, energy cycling) get one full-suite retry before counting; ASSERTION failures (wrong pillars, dead route) are real first time. Known noise (never report): `loading` redirecting to `reveal`; direct-jump mid-flow state on step4a/6a/7a; `read-locked` generic card. ALL THREE health probes failing with no-connection = the test machine lost internet, not an outage — say so, don't alarm.

It refuses non-autofix branches and dirty/diverged main, aborts conflicting branches, re-gates everything (eslint + engine regression + production build), rolls back completely on any gate failure, pushes main (which AUTO-DEPLOYS elementum.life via GitHub Actions — owner-approved), and retires merged branches. Exit 0 = all merged · 1 = partial, report skipped branches · 2 = gates failed and rolled back — mark ⚠️, leave branches, tell the owner.
