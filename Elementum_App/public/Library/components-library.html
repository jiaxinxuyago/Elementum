§13

Open work / drift log

Six gaps neither File A nor File B covers. Specify before shipping affected screens. consolidation drift

These are the holes the consolidation exposed. Each is bounded — not a blocker for the rest of the library, but a flag for engineering not to ship the affected screens without a spec decision. Where the gap is downstream of a third-party (e.g. ink-wash commission for stems), it's marked as such.

D1 · Thumbnail interaction states (hover · selected · locked-loading · video-ready)
§8 ships the seven base patterns but neither file specifies how they respond to touch / hover / selection. Energy Map "draw" interactions need at minimum: hover (subtle lift + paperHair brighten), selected (1.5 px --bronzeDark ring + scale 1.02), locked-loading (shimmer pass while gating decision resolves), and video-ready (small play glyph overlay for the future motion thumbnails). Resolution: draft in v4 — depends on confirmed Energy Map IA.
D2 · Day-master stems — ink-wash commission (DA.2)
Both files flag dm-* symbols as placeholders. The current line glyphs (五·甲·乙…) work as functional fallbacks but they break the painterly register the rest of the system holds. Resolution: external commission. The ten brushwork SVGs will replace the symbols in icons.svg; consumers (this file, all DM-pillar surfaces) will pick up automatically via <use href="…">. No CSS changes required.
D3 · Reading-section icons (DA.9)
read-* symbols are also placeholders. Current geometric line glyphs (pentagram, paired arrows, decade-grid, four-pillars bars) are functional but generic. Resolution: brushwork refinement pass on the five reading-section icons in parallel with the dm-* commission — same painter, same paper register.
D4 · Card pressed / disabled states
Buttons have an 18-cell state matrix (§4). Cards do not. The featured card, compact strip, reading-row card, and element tile all accept taps but neither file specs a press visual or a disabled visual. Resolution: propose a unified card-press spec — scale 0.98 + filter brightness 0.96 + 120ms ease-out — and add a card-disabled visual (opacity 0.5 + pointer-events:none + greyscale 30%) for locked rows that haven't yet upgraded to the lock-card pattern. Draft inline in this file's §7 after sign-off.
D5 · Search bar states beyond default
§5 ships the default search bar. Missing: focus (likely 2 px --borderFocus + ink-text), filled (clear-x chip on the right), with-results (suggestions dropdown — surface unspecified), no-results (italic empty state inside the dropdown), loading (subtle dot pulse where the clear-x would be). Resolution: spec in v4 alongside the Friends search and the future Codex search.
D6 · Toggle disabled state
H4 locks 44 × 26 + 48 × 28 geometry and the on/off pigments. Neither file specs disabled. Resolution: propose opacity 0.4 + knob in the locked position with cursor not-allowed; bg stays in its current state but desaturates 20%. Add to the §5 toggle cell after sign-off.
