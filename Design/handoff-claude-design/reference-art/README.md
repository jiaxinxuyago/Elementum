# Reference art — upload these to Claude Design for art direction

Claude Design can't paint raster or fetch the web, so it needs concrete visual
references for the ink-wash (shuǐmò) aesthetic. Upload these alongside the screen
captures and the master context.

## In this folder (the essential set)
- `01-bold-stroke` … `10-negative-space` — the **brush vocabulary**: stroke
  weight, ink pooling, dry-brush trails, splash dots, mist bands, layered ridges,
  asymmetric branches, calligraphic line, wash gradients, negative space. This is
  the texture/quality bar — backgrounds and motifs should feel hand-painted like
  these, never flat vector.
- `atmospheric-3-layer`, `atmospheric-5-layer` — layered **atmospheric depth** for
  low-opacity page grounds.

## More references in the repo (copy in if a brief needs them)
- `Design/reference/InkWash/FromChrome/` — classical ink-wash landscape scans.
- `Design/assets/Concept Arts/Landscapes/`, `…/Mountains/`, `…/Patterns/`,
  `…/Plants/` — finished concept art per motif.
- `Design/assets/Concept Arts/Five Elements/{Wood,Fire,Earth,Metal,Water}/` —
  per-element painterly art (use the matching element when briefing an
  element-specific surface).
- `Design/assets/Library/art/` — the production thumbnail-card paintings already
  used in-app (match these for any new card art).

## Rule
Use these to set the *quality and feel* of painterly grounds/motifs. Final
painted art is produced separately — mockups may use placeholders, but the
**art-direction intent must match these references** (warm cream paper, soft ink,
generous negative space, no hard vector edges, no neon/mystical clichés).
