The system

Pigments · Legibility recipes

Five pigments, one paper. Each element owns a single hue used at four strengths — a 6% card wash, a 25% border / chip, an 80% eyebrow, and the 100% seal glyph. The ink-wash painting stays warm and monochrome; the hue only tints negative space and frames the type.

Three legibility recipes cover every card. The art is allowed to be busy — the recipe guarantees the words win.

Why the rule exists. Left: type laid straight on the painting — the ink-wash high-contrast passages swallow it. Right: the same crop with the scrim recipe. Pick the recipe, not the gamble.

Don't · no scrim
Forces in Motion
Do · ink scrim
Forces in Motion
  • One raster focal point per screen. A scene-hero OR a strong page-bg — never both at full strength.
  • Pigment wash ≤ 17%. Enough to read the element's temperature; never enough to muddy the ink.
  • Light type → ink scrim. Dark type → solid paper footer. No third option.
  • Seal mark + hanzi do the element labelling so the painting can stay quiet.
  • Crops favour negative space — anchor the subject off-centre, let mist hold the label zone.
  • The red chop is rationed — one seal accent per screen, maximum, like the originals.
