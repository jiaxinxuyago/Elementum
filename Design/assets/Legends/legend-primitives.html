§8

Italic usage gallery

NEW RULE (2026-05-06): Italic is restricted to sub-headlines and microcopy only. Everything else is regular. supersedes §3.5.E
Rule of italic usage · v2

Italic is reserved for two contexts only: sub-headlines and microcopy.

All other text content — element-name labels, composition row names, descriptive paragraphs, body reading copy, CTAs, eyebrows, numerics, status — must be set in regular. The italic voice is no longer the soft-secondary catch-all; it now signals exactly two things: a sub-headline beneath a hero, or a fragment of microcopy.

§12

Drift log · open questions

Where the five inputs disagree or are silent. The anchor is authoritative.
Token divergence — Elementum_App/src/styles/tokens.jsx
Anchor uses opaque paperHair #CDBE9E, borderLight #E5DFD1, borderStd #D5CDBD. App tokens currently define BORDER_LIGHT and BORDER_STD as rgba(139,115,85,*) — a translucent bronze, materially different. Resolution: patch tokens.jsx to the anchor's opaque palette. Anchor wins. DOC5 §3.5 application notes
Tokens present in anchor but absent from tokens.jsx
The anchor's T object exposes paperHair, silkDeep, silkFold, vellum, inkMist, walnut, seal, and the five *Deep element variants (metalDeep, woodDeep, fireDeep, earthDeep, waterDeep). Not all are in app tokens yet. Resolution: add to tokens.jsx verbatim from the anchor.
Spacing values used in anchor that DOC5 §3.5.C does not call out specifically
Anchor line 18 uses gap: 5; the 5/6/8/10 small range is allowed by §3.5.C, but the doc could be clearer that 5 and 6 are intentional (not rounding errors). Same for 22 and 26. Resolution: minor doc-clarification patch — values stay; rationale is added.
Components present in canvas references not covered by §3.5
The pre-Dashboard flow and Reading Pages prototypes contain a three-level hour input (exact / window / unknown), geocoding inline note, and conditional polarity reveal — these are interactions, not visual primitives, so they don't belong in §3.5. Resolution: none — they are screen-specific assemblies of existing primitives. Confirm none introduce new surfaces, radii, or alphas.
Elementum - Visual Directions v2.html · ambient context only
The Visual Directions file is exploratory and predates the anchor lock. Anything it shows that conflicts with northstar-anchor.html is superseded — the anchor wins per the brief's authority rule. Resolution: retire as a source of truth; keep only as historical reference.
Open: BORDER_FOCUS usage in V1
The token exists in both anchor and DOC5 but is unused in V1 reading pages. Confirm with engineering whether onboarding form inputs (Step 1–7) already use it. If yes, document the focus-ring spec; if no, decide whether to apply or leave reserved.
