▸§S0

Brief — what reference synthesis taught us

Eight reference cards across two app families — consolidated.

v4 closed the icon-and-rhythm gaps. The reference review across two batches of mood cards (Mooon astrology & Stellar tarot · 8 cards total) surfaced a set of compositional patterns the legend doesn't yet name. v6 is not a redesign — it's the codification of those patterns into Elementum's vocabulary so they can be reached for by name.

Five takeaways carried forward into this legend:

The five patterns

  • 1 · Element/Pillar tileSquare card · element-pigment gradient as background · ink mark floats large in upper portion · stem hanzi + pinyin label bottom-left ON the gradient. The art is not centered; the composition is asymmetric. (Stellar Big-3 selector)
  • 2 · Section heroFull-width painterly scene with the ink-mark embedded in landscape (cranes over mountains; lantern at dusk; bamboo grove at dawn) · headline + pill CTA overlaid bottom-left · gradient overlay ramps from transparent to ink-translucent. (Mooon premium hero)
  • 3 · Modal-from-cardTapped tile's gradient becomes the modal hero — back-arrow top-left, progress dots top-right, symbol enlarged centre, hanzi+pinyin label bottom-left. The card becomes the sheet header. (Stellar birth-chart detail flow)
  • 4 · Tab strip lives in-cardToday/Tomorrow/Weekly is not at screen level — it sits inside each section card so multiple sections can have independent timeframes. Pill segmented bar, ink-on-silk active. (Stellar home dashboard)
  • 5 · Halftone duotonePhotographic register for browse grids — circular/elliptical photo with halftone dot pattern, bleeding off the right edge of a dark tile. White category label top-left. Useful where bespoke ink is overkill. (Mooon astro/tarot category cards)

What v6 does not do: change tokens, retire any v4 component, or alter the IA. The §V1 brushwork glyphs, the Reveal layout (§V3), the γ inline-expansion plate (§V4), and the tab-bar fade (§V5) all stand. v6 adds composition primitives the existing glyphs and tokens slot into.

▸§S1

StemTile · Day-Master selector grid

Square 1:1 · pigment gradient bg · ink mark floats top-right · hanzi+pinyin bottom-left.

Used wherever the user picks a Heavenly Stem — onboarding (manual override), “explore other stems,” comparison views. Replaces the line-mark placeholder grid that lived in earlier amendment screens. Each tile is a standalone composition: pigment carries the element identity, the floating ink mark carries the brushwork register, the bottom-left label carries the canonical name. The user can recognize a stem by any one of the three.

BranchTile · Earthly-Branch / Hour-Pillar grid

12-up · same vocabulary as §S1, scaled down · element-of-branch drives pigment.

The Branches need their own selector — for hour-pillar entry, “explore the year branch,” and the branch lookup row in Energy Map. Twelve cells fit a phone in a 4×3 grid; each tile inherits the StemTile vocabulary (gradient + grain + floating glyph + bottom-left label) but at smaller scale and with the hanzi character itself substituting for the brushed ink mark — branch glyphs don't yet have v4-quality brushwork, so the character carries the visual weight directly.

BranchTile · differences from StemTile

  • Grid4×3 (12 cells) at phone width · 6×2 in landscape / wider surfaces
  • Element sourceEach branch owns an element (子=water, 丑=earth, 寅=wood, etc.) — drives --{element} through --{element}Deep gradient
  • Floating glyphHanzi character itself, not a brushed ink mark · Noto Serif SC 600 · 30px · cream w/ shadow · top-right
  • LabelPinyin + zodiac animal in one line (cream 88%) · double-hour range below in italic (cream 70%)
  • Hour-pillar useSame tile · the “hour” metadata becomes the primary identifier instead of the animal
  • Anti-patternDon't apply this pattern to a stem grid · don't substitute a ring/circle for the gradient — branches need to read at a glance from element pigment alone
▸§S3

PainterlyHero · element-in-landscape daily reading

Full-bleed scene · ink mark embedded · headline + pill CTA overlaid bottom-left.

The Mooon premium hero pattern — applied to Elementum's daily-pillar and seasonal-pillar moments. Each Heavenly Stem owns a landscape archetype: 甲 = bamboo grove at dawn · 丙 = lantern at dusk · 戊 = mountain in mist · 庚 = sword on stone · 壬 = river waves at twilight. The element symbol is no longer centered on a flat color — it lives in a scene rendered as a layered gradient + silhouette + symbol composition. The headline and CTA overlay bottom-left through a transparent-to-ink gradient veil.

▸§S4

SectionTabs · in-card Today/Tomorrow/Weekly toggle

Each section card carries its own timeframe — not a single screen-level switch.

The Stellar dashboard taught us that different sections want different timeframes. The user might be reading today's pillar but want tomorrow's almanac and this week's hexagram — all on the same screen. v6 codifies the pattern: a small pill-segmented bar lives inside each section card, never at screen level. The Today/Guidance/Reading tabs at the bottom of the app stay as-is (those are app sections); these section-tabs are content-level.

SectionTabs · component spec

  • WhereInside any section card on the home dashboard / Today screen · multiple instances per screen are correct, not a defect
  • Where NOTApp-level navigation (Today/Guidance/Reading/Friends/Profile) · those are tabs at the bottom · this is a different primitive
  • Containerdisplay:flex; gap:0; padding:3px; background:rgba(139,115,85,0.08); border-radius:999px; width:fit-content
  • TabEB Garamond 11px · 1.2px tracking · uppercase · 500wt · padding 6×12 · radius 999
  • Activebackground:var(--silk); color:var(--ink); font-weight:600; box-shadow:0 1px 0 rgba(43,39,34,0.06)
  • State persistenceEach section card holds its own tab state · independent of all other cards · resets on session start
  • Default tabToday (always first) · except Hexagram, where Weekly is the default (the I Ching cadence is naturally weekly)
  • MotionTab body content cross-fades 150ms · the pill itself slides with transform 220ms ease-out
▸§S5

ModalFromCard · stem detail-sheet expansion

Tapped tile's gradient becomes the modal hero · symbol enlarges · label slides down-left.

When a StemTile (§S1) is tapped, it doesn't just navigate — it becomes the top of the next sheet. The gradient enlarges to full-width, the symbol scales up, the hanzi+pinyin label slides from card-corner to sheet-corner. The user reads the tile and the detail as a single continuous object. Same composition language; different size and chrome.

ModalFromCard · component spec

  • TriggerTap on a StemTile (§S1) · system maps tile.gradient → modal-hero.gradient via shared-element transition
  • Hero aspect1.0 / 0.65 · widescreen vs. the 1:1 tile · grows mostly horizontally
  • Symbol scaleFrom 74×74 (tile) → 130×130 (modal) · grows in place via transform:scale · 320ms ease-out
  • Label slideHanzi + pinyin slide from tile-corner to modal-corner · same baseline-anchored typography · 320ms ease-out
  • ChromeBack-arrow top-left (cream pill) · progress-dots top-right (one segment elongated for active) · both fade in 220ms after hero settles
  • Body sheetCream cardstock below hero · standard reading typography · scrolls under hero on long content
  • Reduced motionSnap into place · skip the shared-element flight · chrome fades only
▸§S6

HalftoneTile · second register for browse grids

Photographic duotone with halftone pattern · for Explore · category cards · supplementary content.

Where a brushed ink-mark would be overkill (Explore screens, supplementary content shelves, “more from this section” rows), a second register exists: halftone duotone photography. Dark tile background. Photographic shape (circular or elliptical) bleeds off the right edge with halftone overlay. White category label top-left. No body copy. The pattern lifts directly from the Mooon astro/tarot category cards but uses Elementum's pigments and ink color.

HalftoneTile · usage rules

  • Use caseBrowse grids only · category cards on Explore · "more from {section}" shelves · NOT for any pillar / stem / branch / hexagram individual reading (those use §S1/S2/S3)
  • Tile bgNear-black #1c1612 · provides the contrast the halftone photo needs
  • Photo shapeElliptical, bleeds off the right edge by ~8% · border-radius:50% / 38% creates the slightly-wider-than-tall organic shape
  • Duotone gradientTwo-stop linear · light element-pigment top-left → element-Deep bottom-right · matches the section it categorizes
  • Halftone overlayRadial cream gradient at center · mix-blend-mode:overlay · fakes the dot pattern at small sizes
  • Eyebrow + labelCinzel 9px eyebrow (cream 60%) · Cormorant 21px label below (cream 100%) · top-left z3 over the dark tile, NOT over the photo
  • MetaEB Garamond italic 11px (cream 60%) · bottom-left · count or tier indicator
  • Anti-patternDon't use this register and the painterly hero (§S3) on the same screen — pick one · don't put a halftone tile alongside StemTiles in the same grid · the registers don't mix at row level
