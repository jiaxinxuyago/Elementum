Notes for sending to ChatGPT

A short checklist before zipping and uploading.

1 — Verify references match intent

Open references/ in your file browser. If any of the 20 JPGs look off-style for what you want (e.g. a mountain reference that's too cluttered for the intended quiet hero), swap it with a different file from the original concept-art folders before zipping.

2 — Confirm the targets list still applies

If you want fewer/more backgrounds, edit 01_targets.md and the table above to match. Keep filenames descriptive and aspect ratios in the legal set: 9:16, 16:9, 4:3, 3:4, 1:1.

3 — Zip and upload

Zip the entire ChatGPT_Backgrounds_v1/ folder. Drop into a new ChatGPT conversation in the existing project. Paste this brief: "Here's a curated reference board and target list. Generate the 19 backgrounds in 01_targets.md using the references in references/ as style anchors. Use the DALL-E prompt template in 00_README.md for each."

4 — Iterate by group

Generate in groups of 4 (DALL-E 3 parallel limit), pause to evaluate against §5 quality sniff tests in 02_style_anchors.md, refine if a batch drifts.
