Elementum · Production Asset Library

Thumbnail Card Library

The pull-from library for every card in the app. Five-element themed cards (catalogue, square, portrait) carry the element's pigment and 6–8 motif variants each; generic cards (heroes, banners, life-chapter, pillar, guidance) are neutral high-res ink-wash from the Concept Arts paintings. All art is run through the shared shuǐmò treatment so themed and generic read as one family. Mapped to the screens in Rendered Screens.
